# GATE 论文方法：系统化总结

> 论文：*Improving Treatment Effect Estimation with LLM-Based Data Augmentation*  
> 发表：ICML 2025 Foundation Models for Structured Data Workshop  
> 本文先总结论文原方法，再说明其与大规模 RCT 补贴场景的关系。

## 一、一段话概括

GATE 是一个利用预训练生成模型增强 CATE/Uplift 训练数据的框架。它关注小样本观察数据中的两个问题：一是每个 treatment 分支能够使用的真实样本有限，结果模型估计方差较大；二是 treatment 和 control 人群的特征分布可能不同，模型不得不在缺少对应样本的区域外推。GATE 使用 LLM 为用户生成未观察到的反事实结果，并通过多次生成结果的方差衡量 LLM 的不确定性，只把低不确定性的生成结果加入训练集。增强后的数据继续交给普通 S-Learner、T-Learner、DR-Learner、TARNet 等 CATE 模型训练。LLM 不直接输出最终 uplift，也不能真正观测个体反事实；它提供的是可能有帮助、但也可能有偏差的合成训练标签。

## 二、研究背景

### 2.1 个体反事实不可同时观测

对于用户 `i`，定义：

- `X_i`：干预前特征；
- `T_i ∈ {0,1}`：实际 treatment；
- `Y_i(0)`：不干预时的潜在结果；
- `Y_i(1)`：干预时的潜在结果。

目标是估计条件平均处理效应：

```text
τ(x) = E[Y(1) − Y(0) | X=x]
     = μ_1(x) − μ_0(x)
```

其中：

```text
μ_0(x) = E[Y(0) | X=x]
μ_1(x) = E[Y(1) | X=x]
```

但是，同一个用户只能接受一种 treatment，因此只能观察一个事实结果：

```text
如果 T_i=0：观察到 Y_i(0)，缺失 Y_i(1)
如果 T_i=1：观察到 Y_i(1)，缺失 Y_i(0)
```

普通深度因果模型并没有消除反事实缺失。模型利用不同 treatment 下大量用户的真实标签，分别学习 `μ_0(x)` 和 `μ_1(x)`，推断时再对同一个用户预测两个潜在结果并相减。

### 2.2 小样本导致潜在结果模型不稳定

每个用户虽然只有一个标签，但整个训练集包含不同 treatment 下的用户。对二元 treatment 而言：

```text
control 用户的真实标签用于学习 μ_0(x)
treatment 用户的真实标签用于学习 μ_1(x)
```

因此，总样本会被分散到不同分支。当总样本较少，或者某个 treatment、局部人群和正样本较少时，对应结果函数的估计方差会很大。最终 uplift 又是两个结果预测之差，两边的误差都会传递到效应估计中。

需要区分：

```text
全局样本量：整个数据集有多少样本

局部有效样本量：在某类相似用户附近，
               每个 treatment 分别有多少真实样本和正样本
```

即使总数据量很大，长尾人群或低频 treatment 仍可能缺少有效样本。

### 2.3 观察数据可能存在协变量偏移

如果 treatment 不是随机分配，而是由历史策略选择，治疗组和对照组可能是不同类型的人：

```text
P(X | T=1) ≠ P(X | T=0)
```

例如，旧策略更倾向于给高流失风险、价格敏感的用户发券。模型需要估计这类用户不发券时的结果，但 control 组中可能很少有相似用户，只能进行分布外外推。

论文将这个问题称为 covariate shift。小样本会进一步放大这种偏移带来的误差。

### 2.4 传统解决方案的局限

已有方法通常从模型侧缓解问题，例如：

- 倾向得分和逆概率加权；
- 平衡表示学习；
- 两阶段 pseudo-outcome；
- GAN 或局部回归反事实插补。

但如果生成模型也只使用当前小规模观察数据训练，它能利用的信息与下游 CATE 模型基本相同。在小样本和强协变量偏移下，生成模型本身也可能不准确。

GATE 因此提出：使用在外部大规模语料上预训练的生成模型，并通过字段名称、任务背景和少量真实样本，调动模型在当前数据之外的先验知识。

## 三、论文要解决的核心问题

GATE 要回答的问题是：

> 在小样本、治疗组和对照组分布不同的情况下，能否使用预训练生成模型补充部分缺失反事实，使两个 treatment 分支获得更多训练样本，并减少协变量偏移？

但直接生成所有反事实会带来新的风险：

```text
减少协变量偏移和估计方差所获得的收益
                  与
生成模型错误所引入的标签偏差
```

必须进行权衡。

因此，GATE 的核心并不只是“让 LLM 生成反事实”，而是：

```text
生成多个反事实结果
        ↓
用生成方差衡量不确定性
        ↓
只接纳低不确定性的生成结果
        ↓
将其作为合成样本训练普通CATE模型
```

## 四、方法定位

GATE 是一个数据增强框架，而不是新的 Uplift 网络结构。

```text
真实观察数据
     ↓
LLM生成候选反事实标签
     ↓
不确定性筛选
     ↓
真实样本 + 合成反事实样本
     ↓
普通CATE/Uplift模型
     ↓
最终uplift预测
```

三类结果需要严格区分：

1. **真实事实标签**：用户实际接受 treatment 后观察到的结果；
2. **生成反事实标签**：LLM 对未发生 treatment 的结果所做的近似生成；
3. **最终潜在结果和 uplift**：下游 CATE 模型在增强数据上训练后产生的预测。

LLM 的生成结果不是个体的真实反事实，也不是最终直接使用的 uplift。

## 五、具体实施过程

### 步骤一：准备观察数据

原始数据为：

```text
D_obs = {(X_i, T_i, Y_i)}，i=1,…,n
```

论文采用标准因果识别假设：

1. **一致性**：实际接受 treatment `t` 时，观察结果等于 `Y(t)`；
2. **可忽略性**：给定 `X` 后，treatment 分配与潜在结果独立；
3. **重叠性**：每类特征的用户都有非零概率进入不同 treatment。

这些假设不会因为使用 LLM 而自动成立。GATE 是估计层的数据增强方法，不负责解决未观测混淆。

### 步骤二：确定每个用户缺失的反事实分支

在二元 treatment 下：

```text
若 T_i=0：保留真实 Y_i(0)，需要生成候选 Y_i(1)

若 T_i=1：保留真实 Y_i(1)，需要生成候选 Y_i(0)
```

例如：

```text
用户A实际未发券：T_A=0
实际未来7天未下单：Y_A(0)=0

缺失反事实：如果用户A发券，Y_A(1)=?
```

### 步骤三：构造包含任务语义和真实示例的 Prompt

论文的 Prompt 主要包含四部分。

#### 3.1 任务背景

描述当前因果任务、数据采集场景和希望生成的结果，例如：

```text
根据用户干预前特征，生成其在相反干预状态下的潜在结果。
```

#### 3.2 特征、treatment 和结果的业务含义

向 LLM 说明字段含义，而不是只提供匿名编号：

```text
active_days_30d：最近30天活跃天数
coupon_redeem_rate：历史优惠券核销率
price_sensitivity：历史价格敏感度
T：是否发放优惠券
Y：未来7天是否下单
```

字段语义用于激活 LLM 预训练获得的领域知识。论文的消融实验表明，保留业务背景和字段含义通常优于只使用 `Feature_1`、`Feature_2` 等匿名名称，尤其是在小样本场景。

#### 3.3 不同 treatment 组的结果统计

Prompt 中还提供各组结果的均值、最小值和最大值，帮助 LLM 生成符合数据尺度的结果。

#### 3.4 In-context examples

论文将一批真实观察样本序列化后放入 Prompt：

```text
样本1：特征 + 实际treatment + 真实结果
样本2：特征 + 实际treatment + 真实结果
……
目标样本：特征 + 相反treatment + 待生成结果
```

论文默认每个 Prompt 使用 100 个 in-context 样本，并随机打乱顺序。由于上下文长度有限，作者先把数据随机分组，再为每个目标样本构造其所在分组对应的 Prompt。

### 步骤四：多次调用 LLM 生成候选反事实

对于每个需要增强的 `(X_i,t)`，从 LLM 的生成分布中采样 `K` 次：

```text
Y_i,1(gen)(t), Y_i,2(gen)(t), …, Y_i,K(gen)(t)
```

论文设置：

```text
LLM：GPT-3.5 Turbo
K = 10
temperature = 0.9
```

候选反事实标签取多次生成的平均值：

```text
Y_i(gen)(t) = Mean[Y_i,1(gen)(t), …, Y_i,K(gen)(t)]
```

使用较高但不过度的温度，是为了保留生成随机性，使后续能够根据多次结果的离散程度估计不确定性。温度过低会让输出过于一致，难以识别模型不确定性；温度过高则可能产生异常值。

### 步骤五：用生成方差估计 LLM 不确定性

GATE 将同一候选反事实的多次生成方差作为不确定性分数：

```text
s(x,t) = Var[Y(gen)(t) | X=x]
```

例如：

```text
用户A的10次生成：0.31、0.34、0.32、0.35、……
均值约为0.323，方差较小
```

论文将其解释为 LLM 对该反事实相对稳定。

如果另一个用户的生成结果在 `0.05～0.90` 之间大幅波动，则认为 LLM 不确定性较高。

需要注意：

```text
低方差只表示生成稳定，不保证生成正确；
LLM也可能稳定地生成错误结果。
```

因此，方差是生成可靠性的启发式代理指标，而不是真实误差。

### 步骤六：构造可接纳集合

论文使用分位数阈值控制接纳比例。给定 `α ∈ [0,1]`，先计算所有候选结果的不确定性，再取第 `α` 分位数作为阈值：

```text
λ = Quantile_α({所有候选反事实的不确定性分数})
```

只保留满足以下条件的候选反事实：

```text
s(x,t) < λ
```

这些样本形成 admissible set，即可接纳集合。

论文默认 `α=0.5`，可以通俗理解为大致保留不确定性最低的 50% 生成结果。

`α` 控制生成覆盖率和标签偏差之间的权衡：

```text
α较小：保留结果少，生成偏差较低，但数据增强作用有限

α较大：保留结果多，协变量偏移下降更多，但可能加入更多错误标签
```

### 步骤七：构造增强训练集

最终数据集由真实观察样本和通过筛选的生成样本组成：

```text
D_aug = D_obs ∪ D_generated,accepted
```

对于实际未发券的用户 A：

```text
真实样本：(X_A, T=0, Y=0)

若生成结果通过筛选，增加：
(X_A, T=1, Y=0.323)
```

真实样本始终保留；只有通过不确定性筛选的生成结果才会加入数据集。

理想情况下，增强后 treatment 和 control 数据包含更加相似的协变量覆盖：

```text
原始数据：不同分支只覆盖各自实际进入该组的用户

增强数据：部分用户同时以真实事实样本和合成反事实样本出现
```

### 步骤八：训练普通 CATE/Uplift 模型

GATE 不规定新的下游网络。论文将增强数据分别交给：

- S-Learner；
- T-Learner；
- X-Learner；
- R-Learner；
- IPW-Learner；
- DR-Learner；
- CFR、TARNet、DragonNet、BART 等。

以 T-Learner 为例：

```text
μ̂_0(x)：使用T=0的真实样本和接纳的生成样本训练

μ̂_1(x)：使用T=1的真实样本和接纳的生成样本训练

τ̂(x) = μ̂_1(x) − μ̂_0(x)
```

推断时，由下游模型对同一个用户预测两个结果并相减。LLM 的单次生成值不会直接作为最终 uplift。

## 六、补贴场景示例

假设：

```text
T=0：不发券
T=1：发5元券
Y：未来7天是否下单
```

用户 A 的数据为：

```text
最近30天下单2次
最近7天没有下单
历史券核销率70%
价格敏感度较高
最近活跃下降

实际未发券：T=0
未来7天未下单：Y(0)=0
```

GATE 的处理过程为：

```text
1. 在Prompt中描述业务、字段和真实示例

2. 让LLM生成“用户A发5元券后的结果”10次

3. 计算10次结果的平均值和方差

4. 如果方差低于分位数阈值，把平均值作为候选Y(gen)(1)

5. 将(X_A,T=1,Y(gen)(1))加入增强训练集

6. 使用增强数据训练EUEN或其他Uplift模型

7. 推断时仍由Uplift模型输出μ̂_0(X_A)、μ̂_1(X_A)和二者之差
```

例如，模型最终输出：

```text
μ̂_0(X_A) = 0.08
μ̂_1(X_A) = 0.30

τ̂(X_A) = 0.30 − 0.08 = 0.22
```

这里的 `0.22` 是下游模型基于全部训练数据得到的 CATE 预测，不是直接采用 LLM 生成的结果。

## 七、实验设计与主要结论

论文使用 Lalonde、STAR Project 和 Hillstrom 等数据集，以 PEHE 衡量 CATE 估计误差：

```text
PEHE越低，表示预测异质性效应越接近基准真值
```

主要结论包括：

1. 在多种 CATE learner 上，GATE 增强后平均 PEHE 通常下降；
2. LLM 相对均值插补、最近邻、随机森林、GAN 和 TabPFN 等方法的优势在小样本时更明显；
3. 提供真实字段含义和任务背景，通常优于使用匿名特征；
4. 增加 in-context examples 有助于改善生成效果；
5. 协变量偏移越强，GATE 的潜在收益越大；
6. 增加接纳比例会进一步减少协变量偏移，但同时增加生成标签误差；
7. 基于生成方差的筛选在多数小样本实验中优于随机筛选和倾向得分筛选。

论文的结论应按其证据边界理解：它发表于 workshop，数据集规模和业务复杂度有限，主实验为二元 treatment，并未验证大规模、多档补贴生产系统。

## 八、GATE 与普通深度因果模型的关系

### 8.1 普通 EUEN 如何使用一个真实标签训练

每个用户只有一个真实结果，但整个数据集包含不同 treatment 的用户：

```text
control用户监督control结果分支
treatment用户监督treatment结果分支
```

对用户 `i`，事实结果预测可以写为：

```text
ŷ_i,factual = (1−T_i) × μ̂_0(X_i) + T_i × μ̂_1(X_i)
```

训练只计算事实分支的损失：

```text
L_i = Loss(Y_i, ŷ_i,factual)
```

推断时才让同一个用户同时经过所有分支：

```text
τ̂(X_i) = μ̂_1(X_i) − μ̂_0(X_i)
```

缺失分支通过其他相似用户的事实数据间接学习。

### 8.2 GATE 增加的内容

普通 EUEN：

```text
用户A实际进入treatment分支
→ 只有该分支获得A的真实监督
```

GATE：

```text
在保留A的真实事实样本之外
→ 尝试给A缺失的control分支增加一个合成监督信号
```

因此，GATE 并没有解决反事实不可观测，而是用生成模型近似部分缺失标签。

## 九、适用条件与局限

### 9.1 最适合的场景

GATE 更可能适用于：

- 总体样本较少；
- 某个 treatment 分支样本较少；
- 正样本极度稀疏；
- 观察数据存在明显协变量偏移；
- 新城市、新业务或新 treatment 冷启动；
- 字段具有清晰语义，LLM 可能具有相关外部知识。

### 9.2 大规模 RCT 场景中的价值有限

如果数据满足：

```text
训练样本充足
各treatment真实样本和正样本充足
RCT随机化可靠
关键人群具有良好overlap
```

那么 GATE 的两个主要动机都会减弱：

1. 大规模 RCT 已经显著降低 treatment/control 的协变量偏移；
2. 真实实验标签通常比 LLM 生成的反事实更可靠。

此时加入合成标签可能带来有限收益，同时把 LLM 的错误先验引入原本干净的 RCT 数据。

### 9.3 总样本大不代表所有局部区域都充足

仍需检查：

```text
城市 × 用户类型 × 商户类型 × treatment × 结果
```

在长尾人群、低频 treatment 或极低转化率区域，局部有效样本量可能仍然不足。GATE 在这些局部问题上可能具有探索价值。

### 9.4 生成方差不是正确性保证

LLM 可能：

- 稳定地产生错误结果；
- 将常识相关性误认为因果关系；
- 忽略平台特有的补贴机制；
- 生成不满足校准性或业务约束的结果。

因此，不能把低方差的生成结果视为真实标签。

### 9.5 多 treatment 扩展尚未充分验证

论文主要研究二元 treatment。若补贴场景包含：

```text
control、3元券、5元券、8元券
```

每个用户会缺失多个潜在结果，需要分别生成和筛选，LLM 调用成本、错误累积和 treatment 间一致性问题都会显著增加。

### 9.6 计算成本较高

论文对每个候选反事实生成多次结果。对于百万至千万级训练数据，直接全量使用成本很高。生产探索应优先考虑：

- 只处理稀疏 treatment；
- 只处理模型高不确定样本；
- 只处理关键长尾分群；
- 先在代表性样本或聚类中心上验证；
- 缓存全部生成结果。

## 十、在当前补贴项目中的建议

结合“大规模 RCT + 深度因果模型 + 下游运筹”的现状，GATE 不适合作为全量训练链路的第一优先升级。更值得优先探索的方向是：

1. 使用 DFCL 对齐 Uplift 预测与最终补贴分配目标；
2. 使用 CURL 或其他方法探索 LLM 语义表征增强；
3. 改进多 treatment 联合建模、单调性和跨档位一致性；
4. 将 GATE 限定为小样本、稀疏 treatment 和冷启动专项实验。

如果验证 GATE，建议使用受控学习曲线实验：

```text
分别取1%、5%、10%、50%、100%的真实RCT训练数据

每个数据量分别训练：
原始EUEN
GATE增强EUEN

比较：
AUUC、Qini、分桶校准、策略价值和不同人群的稳定性
```

需要重点检验的假设是：

```text
小样本时，GATE可能降低估计方差；
随着真实RCT样本增加，GATE的边际收益应逐渐缩小；
全量数据下，生成偏差可能抵消甚至超过增强收益。
```

## 十一、与 CURL、DFCL 的位置关系

三种方法作用于不同环节：

```text
CURL：LLM生成语义表征
      → 增强因果模型输入

GATE：LLM生成候选反事实标签
      → 增强因果模型训练数据

DFCL：使用下游分配质量构造决策损失
      → 对齐因果预测与运筹目标
```

对应完整链路：

```text
结构化特征 ──→ CURL语义增强 ──┐
                              ↓
真实实验数据 ─→ GATE数据增强 ─→ EUEN/CATE模型 ─→ uplift ─→ 运筹分配
                                                   ↑
                                                 DFCL
```

这三种思路不是同一种方法，也不需要同时使用。对当前项目而言，应先根据真实瓶颈选择对应环节，而不是为了使用 LLM 而增加生成模块。
