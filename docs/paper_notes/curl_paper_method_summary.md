# CURL 原论文方法：系统化总结

> 论文：*Uncertainty-Guided LLM Semantic Augmentation for Heterogeneous Treatment Effect Estimation*  
> 本文仅总结 CURL 的原始方法，不包含针对 EUEN 或补贴业务的改造方案。

## 一、方法概述

CURL 是一个面向 CATE/ITE 估计的 LLM 语义增强框架。该方法不使用 LLM 直接预测个体治疗效应，而是先训练原有因果模型，再根据模型的不确定性识别难以估计的样本；随后，将这些样本的干预前特征转换为自然语言画像，并通过两个独立的角色 Prompt，分别提取与治疗分配和效应异质性有关的语义向量；最后，通过投影、门控和分支路由将语义向量接入原模型，并联合优化原因果任务、倾向得分任务和语义解耦任务。整个过程以多轮方式进行，使有限的 LLM 计算资源持续分配给当前最需要语义补充的样本。

CURL 估计的目标仍然是条件平均治疗效应：

```text
τ(x) = E[Y(1) − Y(0) | X = x]
```

其中，`Y(1)` 和 `Y(0)` 分别表示接受干预和不接受干预时的潜在结果，`τ(x)` 表示特征为 `x` 的人群的平均增量效果。

## 二、方法定位

CURL 关注的是**表示能力不足**问题：原始协变量可能已经包含因果识别所需的信息，但简单的数值或类别编码未能充分表达字段之间的语义联系，导致有限样本下的 CATE 模型难以学习混淆结构和效应异质性。

因此，CURL 的职责是利用 LLM 重组已有协变量中的语义关系，而不是补造新的用户事实，也不改变原模型的目标变量和因果识别假设。

## 三、训练流程

### 步骤一：初始化基础因果效应模型

首先，使用原始结构化特征训练一个不包含 LLM 语义的 CATE/ITE 模型。该模型称为 host learner，可以是 S-Learner、T-Learner、R-Learner、TARNet、CFRNet、DragonNet 等。

这一阶段的作用包括：

1. 获得可工作的基础因果效应模型；
2. 建立原始特征表示；
3. 为后续的不确定性诊断提供初始预测结果。

此时所有语义输入均设为零，模型完全按照原有路径训练。

```text
输入：训练数据 D = {(X_i, T_i, Y_i)}
处理：按照 host learner 的原始目标进行训练
输出：未使用 LLM 语义的基础模型 F(0)
```

### 步骤二：基于双重不确定性的样本诊断与选择

该步骤用于确定本轮应为哪些样本调用 LLM。它选择的是**当前模型最难稳定估计的样本**，而不是选择应该接受干预的用户。

#### 2.1 进行多次随机预测

对每个训练样本开启 Dropout，并重复执行 `M` 次前向预测。由于每次随机丢弃的神经元不同，同一样本会得到多组倾向得分和治疗效应预测。论文默认 `M = 30`。

#### 2.2 计算两类不确定性

以多次预测结果的标准差衡量模型的不稳定程度：

```text
分配不确定性：s_e(i) = Std[ê_i(1), ê_i(2), …, ê_i(M)]

效应不确定性：s_τ(i) = Std[τ̂_i(1), τ̂_i(2), …, τ̂_i(M)]
```

- `ê_i(m)`：第 `m` 次前向计算对样本 `i` 输出的倾向得分，即模型估计的 `P(T=1 | X_i)`；
- `τ̂_i(m)`：第 `m` 次前向计算对样本 `i` 输出的 CATE/ITE。对于分别预测两种潜在结果的模型，通常有 `τ̂_i(m) = μ̂_1,i(m) − μ̂_0,i(m)`；
- `s_e(i)`：`M` 个倾向得分的标准差，用于衡量治疗分配预测是否稳定；
- `s_τ(i)`：`M` 个治疗效应预测的标准差，用于衡量个体效应预测是否稳定。

这些数值不是对同一用户进行 `M` 次真实实验得到的结果，而是同一个已训练模型在开启 Dropout 后，对同一组输入特征进行 `M` 次随机前向计算的输出。每次计算使用不同的 Dropout 掩码，因此结果的离散程度可以近似反映模型的不确定性。

第一轮中，如果原模型尚未提供倾向得分输出，则统一令 `s_e(i) = 0`，仅根据效应不确定性进行初始选择。

#### 2.3 统一量纲并计算综合排名

两类不确定性的原始数值范围可能不同，因此不能直接相加。CURL 先将二者分别转换为训练集内的百分位排名，再计算综合分数：

```text
q_i = PRank[s_e(i)] + PRank[s_τ(i)]
```

其中，`PRank` 表示百分位排名。经过转换后，两类分数均位于 `0～1`，从而可以近似等权比较。

#### 2.4 选择样本并更新缓存

按照综合分数 `q_i` 从高到低排序，选择排名最高的前 `ρN` 个样本：

```text
S(r) = 第 r 轮综合不确定性最高的前 ρN 个样本
```

论文默认每轮选择比例 `ρ = 0.25`。设 `C(r−1)` 为此前已经生成过语义向量的样本集合，则本轮真正需要调用 LLM 的新样本为：

```text
Q(r) = S(r) − C(r−1)

C(r) = C(r−1) ∪ S(r)
```

三个集合的含义分别是：

- `S(r)`：第 `r` 轮根据不确定性排名选中的全部样本；
- `C(r−1)`：进入第 `r` 轮之前，已经调用过 LLM 并保存了语义向量的全部样本；
- `Q(r)`：本轮选中、但过去从未调用过 LLM 的新增样本。

第一条公式用集合差集排除已经处理过的样本，因此只有 `Q(r)` 中的样本需要在本轮调用 LLM。第二条公式用集合并集更新累计缓存，将本轮选中的样本加入历史缓存。

例如：

```text
本轮选中集合：S(r)     = {用户1, 用户2, 用户3, 用户4}
历史缓存集合：C(r−1)   = {用户1, 用户2, 用户8}

本轮新增查询：Q(r)     = {用户3, 用户4}
更新后的缓存：C(r)     = {用户1, 用户2, 用户3, 用户4, 用户8}
```

因此，本轮只需要为用户3和用户4调用 LLM。用户1和用户2虽然再次被判定为高不确定样本，但已有语义向量，可以直接从缓存读取。这样可以保证每个训练样本最多调用一次 LLM。

### 步骤三：构造确定性的自然语言用户画像

对于本轮新增的高不确定样本，CURL 使用数据集特定的固定模板，将结构化协变量转换为自然语言画像：

```text
p_i = ψ(x_i)
```

其中，`ψ` 是人工定义的确定性模板，而不是 LLM。该转换过程不调用 LLM，只负责将字段编码还原为具有明确业务含义的描述。

例如，结构化特征为：

```text
recency = 9
mens_purchase = 1
history = 900.73
channel = "Phone"
```

经过固定模板转换后可以得到：

```text
该用户距离上次与品牌互动已经过去9个月，购买过男装，
历史消费金额为900.73美元，主要使用电话渠道交易。
本次干预是发送男装营销邮件；对照是不发送营销邮件。
```

用户画像只能包含干预发生前已经观测到的信息，以及整个数据集统一的干预定义。以下信息不得写入画像：

- 该样本实际接受了哪一种干预；
- 干预后的结果；
- 反事实结果或真实 uplift；
- 模型预测误差和测试集统计信息。

这一限制用于避免标签泄漏，并保证 LLM 只重组已有协变量中的语义关系。

### 步骤四：调用 LLM 并提取双通道语义向量

CURL 对每个新增样本使用两个相互独立的 Prompt，分别构造分配语义和效应异质性语义。

#### 4.1 生成数据集级背景提示

在训练初始化阶段，CURL 比较首轮高不确定样本与完整训练集的数值特征均值，保留相对差异超过 20% 的至多 10 个字段，并调用一次 LLM，将这些总体差异概括为一句 `insight hint`。

该提示反映高不确定人群的总体特征，只在初始化时生成一次，随后保持不变。它不包含任何单个样本的治疗标签或结果。

#### 4.2 构造两个角色 Prompt

**分配视角 Prompt**用于分析：

- 哪些干预前特征可能影响治疗分配；
- 哪些特征也可能影响用户的自然结果；
- 哪些特征关系可能与混淆调整有关。

**异质性视角 Prompt**用于分析：

- 哪些稳定的干预前属性可能改变治疗响应；
- 哪些特征组合可能代表更高或更低的干预敏感度；
- 哪些语义关系可能帮助区分不同受益人群。

两个 Prompt 独立调用和缓存，避免将“为什么接受干预”与“接受干预后是否更受益”混为同一种信息。

#### 4.3 提取隐藏状态向量

对于每个 Prompt，冻结的 LLM 依次执行：

1. 根据 Prompt 生成确定性的文字分析；
2. 将“Prompt + 生成的分析”再次输入同一个 LLM；
3. 读取最后一个有效回答 token 在最后一层的隐藏状态；
4. 将隐藏状态作为对应通道的语义向量并写入缓存。

```text
z_A(i) = LLM_Embedding(分配视角 Prompt_i)

z_H(i) = LLM_Embedding(异质性视角 Prompt_i)
```

其中，`z_A(i)` 为分配语义向量，`z_H(i)` 为效应异质性语义向量。生成的文字只用于引导 LLM 组织信息和供研究者检查；真正进入因果模型的是隐藏状态向量。

#### 4.4 构造稀疏语义输入

两个 LLM 向量生成后会被永久缓存，但在第 `r` 轮中，只有已经进入累计语义集合 `C(r)` 的样本可以向适配器提供非零语义输入：

需要特别说明：CURL 并不会先为全部样本生成 LLM 向量再进行筛选。只有本轮新增的高不确定样本 `Q(r)` 才会调用 LLM并生成向量；从未入选的样本没有 LLM 向量，训练时仅使用同维度的零向量作为占位。

```text
z_q(i, r) = I[i ∈ C(r)] × z_q,LLM(i)，q ∈ {A, H}
```

其中，`q = A` 表示分配语义通道，`q = H` 表示异质性语义通道，`I[·]` 是取值为 0 或 1 的指示函数：

```text
如果 i ∈ C(r)：I = 1，使用该样本已经缓存的 LLM 向量

如果 i ∉ C(r)：I = 0，向适配器输入同维度的零向量
```

例如，第 `r` 轮累计缓存中只有用户1和用户3：

```text
用户1：z_A(1, r) = z_A,LLM(1)，z_H(1, r) = z_H,LLM(1)
用户2：z_A(2, r) = 0，          z_H(2, r) = 0
用户3：z_A(3, r) = z_A,LLM(3)，z_H(3, r) = z_H,LLM(3)
```

因此，用户1和用户3沿用语义增强路径，用户2没有被选中，仍沿用原始 host learner 路径。这里的指示函数是控制“是否具有语义输入”的硬开关；下一步骤中的 `α_i` 和 `β_i` 则是在已有语义的前提下，进一步学习“语义应当注入多少”的软门控。

### 步骤五：投影、门控并融合双通道语义

该步骤将 LLM 语义向量转换为原因果模型可以使用的特征，并按照两种语义的职责将其送入不同分支。

#### 5.1 语义投影

两个语义向量首先通过独立的可训练投影器，映射到与 host learner 相适配的特征空间：

```text
v_A(i) = Projector_A[z_A(i)]

v_H(i) = Projector_H[z_H(i)]
```

LLM 参数保持冻结，投影器随原因果模型一起训练。

#### 5.2 不确定性门控

CURL 根据两类不确定性学习每种语义的注入强度：

```text
α_i = I(i 已有语义) × Sigmoid[MLP_A(s_e(i))]

β_i = I(i 已有语义) × Sigmoid[MLP_H(s_τ(i))]
```

- `α_i` 控制分配语义的使用强度；
- `β_i` 控制异质性语义的使用强度；
- `I(·)` 是指示函数。未被选中的样本取 0，继续沿用未增强的原模型路径。

#### 5.3 非对称融合与角色路由

设原因果模型产生的基础表示为 `u_i`，CURL 采用以下融合方式：

```text
分配增强表示：u_A(i) = u_i + α_i × v_A(i)

效应增强表示：u_H(i) = Concat[u_A(i), β_i × v_H(i)]
```

两个表示被送入不同预测分支：

```text
倾向得分预测：ê_i = PropensityHead[u_A(i)]

治疗效应预测：τ̂_i = EffectModel[u_H(i)]
```

分配语义通过残差加法补充共享表示，并参与倾向得分预测；异质性语义作为独立特征块，只进入效应预测分支，不直接进入倾向得分分支。

这里的“共享表示”是指同时被倾向得分模块和效应预测模块使用的中间用户表示，而不是某一个单独的预测结果。具体数据流为：

```text
基础表示 u_i + 分配语义
            ↓
      共享表示 u_A(i)
         ├────────→ 倾向得分头 → ê_i
         │
         └─ 与异质性语义拼接 → u_H(i) → 效应预测模块 → τ̂_i
```

因此，分配语义 `v_A(i)` 会间接影响两个任务：一方面帮助估计该用户接受干预的概率，另一方面作为效应估计的基础信息参与混淆调整。异质性语义 `v_H(i)` 只在形成 `u_H(i)` 时加入，所以只能影响潜在结果或 CATE 的预测，不能影响倾向得分 `ê_i`。

以优惠券场景为例，“历史营销触达、自然下单倾向、渠道活跃度”等信息可能同时关系到是否被发券和原本是否会下单，因此进入共享表示；“价格敏感度、优惠使用偏好、券面额匹配度”等响应修饰信息主要用于判断发券后增量效果，因此只进入效应预测模块。这里的两类描述是语义角色划分，不代表模型发现了真实且唯一的因果因素。

### 步骤六：联合训练并进行渐进式更新

CURL 同时优化三个训练目标：

```text
L_total = L_main + λ_prop × L_prop + λ_ortho × L_ortho
```

其中：

1. `L_main`：host learner 原有的结果预测或因果效应学习损失；
2. `L_prop`：倾向得分预测损失；
3. `L_ortho`：分配语义与异质性语义的正交约束。

```text
L_prop  = 平均 BCE(ê_i, T_i)

L_ortho = 平均 CosineSimilarity[v_A(i), v_H(i)]²
```

论文默认 `λ_prop = 1.0`、`λ_ortho = 0.1`。正交约束用于降低两个语义通道的重复程度，但不能证明它们对应真实且唯一的因果机制。

完成一轮联合训练后，模型重新执行步骤二至步骤六：重新诊断不确定性、发现新的困难样本、补充语义并继续优化。论文默认进行 `R = 3` 轮。各轮之间不重新初始化模型和优化器，而是在当前参数基础上持续训练。

## 四、完整训练链路

```text
训练基础 CATE 模型
        ↓
估计分配不确定性与效应不确定性
        ↓
选择综合不确定性最高的样本
        ↓
将结构化协变量转换为自然语言画像
        ↓
调用两个角色 Prompt，提取双通道语义向量
        ↓
对语义向量进行投影、门控和分支路由
        ↓
联合优化主任务、倾向得分任务和正交约束
        ↓
重新诊断不确定性并进入下一轮
```

## 五、测试阶段的推理流程

对于一个未见过的新样本，CURL 不会立即调用 LLM，而是先通过未增强路径估计其不确定性：

1. 将语义输入设为零，执行多次随机前向预测；
2. 计算分配不确定性和效应不确定性；
3. 将两类不确定性映射到训练集百分位；
4. 与训练阶段保存的选择阈值比较；
5. 低于阈值时，直接使用原模型预测；
6. 高于阈值时，构造用户画像并生成双通道语义，再输出增强后的 CATE/ITE。

选择条件为：

```text
G_e[s_e(*)] + G_τ[s_τ(*)] ≥ κ_ρ
```

其中，`G_e` 和 `G_τ` 是训练集两类不确定性的百分位映射，`κ_ρ` 是训练阶段保存的选择阈值。

## 六、方法的关键边界

- CURL 不能解决未观测混淆。LLM 对缺失属性的推测不能替代真实观测。
- LLM 提供的是辅助语义表示，不是新的用户事实或可以直接执行的因果结论。
- MC Dropout 的标准差是样本分配指标，不是严格校准的统计置信区间。
- 正交损失只减少两个表示的重复性，不提供可识别的因果因素分解。
- 原论文主要处理二元干预，不直接处理连续治疗、多档补贴、预算约束或序列决策。
- 测试阶段仍可能需要多次前向计算和 LLM 推理，需要考虑线上成本与时延。

## 七、核心理解

> CURL 先让原因果模型识别自身最难稳定估计的样本，再由冻结的 LLM 从治疗分配和效应异质性两个角度重组这些样本已有的干预前信息，最后通过受约束的双通道融合增强原因果模型；最终的 uplift 仍由原因果模型预测，而不是由 LLM 直接生成。
