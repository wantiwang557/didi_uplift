# 端到端因果决策：从 Uplift＋OR 到大模型决策

> 调研日期：2026-10-09  
> 业务范围：多券补贴、CATE/Uplift、成本与预算约束、运筹分配  
> 本文先梳理不依赖 LLM 的传统端到端方法，再讨论基础模型、生成式模型和 LLM 的接入方式。

## 一、要解决的核心问题

传统补贴决策通常采用两阶段流程：

```text
第一阶段：预测每个用户在不同券下的增量收益和增量成本
                         ↓
第二阶段：在预算、CAC、库存和配额约束下运行 OR
```

两阶段方法的问题不是 OR 本身，而是两个阶段的训练目标不同：

```text
模型训练目标：减小 outcome 误差、提高 AUUC 或改善 uplift 排序

OR 决策目标：在约束下最大化最终增量收益
```

预测指标改善不一定带来决策价值改善。尤其是在预算边界附近，少数用户或券型的排序错误可能改变最终分配，而大量不影响决策的预测误差即使下降，也未必产生业务收益。

端到端因果决策希望让最终策略价值参与上游模型训练：

```text
用户与券特征
      ↓
因果效应/成本模型
      ↓
优化或策略模块
      ↓
最终分配结果
      ↓
决策价值、regret、约束违例
      ↓
反向影响上游模型
```

## 二、“端到端”有三种不同含义

### 2.1 保留 OR 的决策感知训练

模型仍然预测增量收益和增量成本，部署时仍由 OR 求解；区别在于训练 loss 包含下游决策质量。

```text
预测模型 → OR → 决策损失 → 更新预测模型
```

这是 Decision-Focused Learning（DFL）和 DFCL 的主要范式。

### 2.2 直接策略学习

模型不要求先准确还原所有 CATE，而是直接学习在给定用户和约束条件下选择动作：

```text
π(a | x, λ)
```

其中 `a` 是券型或不发券，`λ` 表示成本惩罚或系统约束压力。训练目标直接是策略价值。

### 2.3 生成式决策

将券型、补贴金额或未来计划表示为 token 或连续轨迹，由 Transformer、扩散模型等直接生成受约束决策。

```text
历史状态 + 全局约束 → 生成补贴动作或补贴计划
```

这种方法可能不再显式运行传统 OR，但通常仍需要奖励模型、拉格朗日约束、校准或执行控制层。

## 三、传统端到端方法如何实现

### 3.1 Predict-then-Optimize 与决策 regret

设模型根据特征 `x` 预测优化问题的未知参数：

```text
ĉ = f_θ(x)
```

优化器根据预测值产生决策：

```text
ẑ = Solver(ĉ)
```

传统监督学习优化预测误差：

```text
L_prediction = Error(ĉ, c)
```

Decision-Focused Learning 更关注该决策在真实参数下的损失：

```text
L_decision = Objective(ẑ, c) − Objective(z*, c)
```

其中 `z*` 是使用真实参数时的最优决策。这个差值通常称为 regret。

代表性基础工作包括：

- [Task-based End-to-end Model Learning in Stochastic Optimization](https://arxiv.org/abs/1703.04529)：将下游随机优化目标用于训练预测模型；
- [Smart Predict, then Optimize](https://arxiv.org/abs/1710.08005)：提出面向线性优化决策 regret 的 SPO/SPO+ 损失；
- [OptNet](https://arxiv.org/abs/1703.00443)：将优化问题作为神经网络层并进行隐式求导；
- [Differentiation of Blackbox Combinatorial Solvers](https://arxiv.org/abs/1912.02175)：通过扰动黑盒求解器近似获得梯度。

### 3.2 端到端训练的三类技术路线

#### 路线 A：可微优化层

对连续、凸优化问题，可以利用 KKT 条件或隐式微分计算：

```text
决策损失对模型参数的梯度
= 决策损失对最优解的梯度
× 最优解对预测参数的梯度
× 预测参数对模型参数的梯度
```

优点是数学链路清楚；不足是多券分配通常包含 0-1 整数变量，连续松弛可能产生部署时不可执行或次优的结果。

#### 路线 B：黑盒求解器梯度估计

把 OR solver 当作黑盒，对预测结果做小幅扰动，观察最优决策变化，并用有限差分或随机扰动近似梯度。

优点是可以保留原有离散求解器；不足是训练时需要频繁调用 solver，计算成本高，梯度也可能不稳定。

#### 路线 C：决策损失的可微替代函数

不直接对离散最优解求导，而是设计连续 surrogate loss，使模型在优化该 loss 时也倾向于产生更好的最终决策。

这种方式更适合大规模营销数据，因为训练复杂度可以接近普通监督学习，但需要证明或实验证明 surrogate 与真实策略价值一致。

## 四、因果营销为什么比普通 DFL 更难

在普通预测优化问题中，训练集可能包含每个决策的真实成本或收益；在补贴业务中，同一个用户只接受一种券，因此其他券下的结果都是反事实。

假设用户 `i` 有多个动作 `a`：

```text
可观测：Y_i(A_i)、C_i(A_i)

不可同时观测：Y_i(a)、C_i(a)，a ≠ A_i
```

这导致三个困难：

1. 无法直接计算某个候选分配方案的真实整体收益；
2. 无法获得使用真实潜在结果求出的最优分配 `z*`；
3. 不能直接把普通 SPO+ 或 regret loss 原样应用到 uplift 场景。

因此，端到端因果决策通常需要 RCT、IPW、DR/EOM 等反事实策略价值估计方法。

## 五、DFCL：补贴场景中的传统端到端代表

[Decision Focused Causal Learning for Direct Counterfactual Marketing Optimization，KDD 2024](https://arxiv.org/abs/2407.13664) 直接针对“多 treatment 效应预测＋预算分配”两阶段割裂问题。

### 5.1 原始优化问题

设 `z_ij` 表示是否给用户 `i` 分配 treatment `j`，`r_ij` 和 `c_ij` 分别表示该动作的收益和成本：

```text
最大化：Σ_i Σ_j z_ij × r_ij

约束一：Σ_i Σ_j z_ij × c_ij ≤ B

约束二：每个用户只能选择一个动作
```

这是带不确定收益和不确定成本的多选背包问题。

### 5.2 DFCL 的主要处理

DFCL 的核心不是把整数规划简单改成一个神经网络，而是处理三个营销特有问题：

1. **预算与成本不确定。** 使用拉格朗日对偶，把预算约束转化为不同乘子下的收益—成本权衡，使模型可以适应不同预算；
2. **反事实不可观测。** 使用策略学习 surrogate，或者基于 Expected Outcome Metric（EOM）估计决策质量；
3. **大规模训练成本。** 使用连续 surrogate 或改进的有限差分方法，减少训练期间频繁求解大规模整数规划的开销。

论文给出两类主要训练思路：

- Policy Learning Loss / Maximum-Entropy Regularized Loss：将离散动作转成概率策略并构造连续损失；
- EOM＋黑盒梯度：用反事实策略价值估计评价决策，并通过改进有限差分估计模型更新方向。

### 5.3 DFCL 的端到端含义

DFCL 仍可保留 OR，但上游模型优化的是最终分配质量，而不是只优化 outcome 误差：

```text
用户特征
   ↓
预测各 treatment 的收益和成本
   ↓
预算分配
   ↓
EOM/策略价值估计
   ↓
决策损失更新模型
```

它是当前项目研究“一二阶段一致性”最直接的传统基线。

## 六、Bi-DFCL：观察数据与实验数据的双层决策学习

[Bi-Level Decision-Focused Causal Learning，NeurIPS 2025](https://arxiv.org/abs/2510.19517) 进一步处理工业中常见的数据矛盾：

```text
观察数据：规模大，但受历史策略和选择偏差影响
实验数据：相对无偏，但样本少、估计方差大
```

它的总体思路是：

1. 使用实验数据构造较可信的 OR 决策质量估计；
2. 用该估计指导 surrogate loss 的学习方向；
3. 在双层优化中使用大规模观察数据训练模型；
4. 通过实验数据校正观察数据带来的偏差；
5. 使用隐式微分连接内层模型训练与外层决策质量。

它仍属于传统深度模型＋因果估计＋OR，不是 LLM 方法。对于“历史策略日志很多、RCT 较少”的业务，它比只使用 RCT 的 DFCL 更有吸引力。

## 七、直接策略学习：不要求先精确还原全部 CATE

另一条传统路线是直接学习：

```text
π_θ(a | x, λ)
```

训练目标可以基于 RCT 或 DR pseudo-outcome：

```text
最大化：E[Σ_a π_θ(a|x,λ) × (增量收益_a − λ × 增量成本_a)]
```

它与 DFCL 的差别是：

| 方法 | 中间是否显式预测 CATE | 部署时是否运行 OR |
|---|---:|---:|
| DFCL | 通常是 | 通常是 |
| 直接策略 | 可以不要求完整 CATE | 可以不运行 |

直接策略更接近最终业务目标，但可解释性、跨预算泛化和硬约束保证通常更弱。对于当前只有少量券型的场景，应该先用小型 MLP 策略作为基线，而不必一开始使用生成式大模型。

## 八、大模型如何进入端到端决策

### 8.1 基础模型接受 Decision-Focused Fine-Tuning

[Decision-Focused Fine-Tuning of Time Series Foundation Models，2025](https://arxiv.org/abs/2503.01936) 使用时间序列基础模型 Moirai 预测能源需求，并让下游调度成本而不是预测误差驱动参数高效微调。

其实现方式是：

```text
预训练基础模型 Moirai
        ↓ 预测未来序列
下游能源调度优化
        ↓ 产生系统成本
可微 surrogate value network
        ↓
通过 LoRA/DoRA 更新基础模型适配器
```

这个工作提供了一个重要先例：大模型不必整体重新训练，可以冻结主体，只让 LoRA/DoRA 等少量参数接受决策目标监督。

迁移到补贴场景后，可以变成：

```text
用户行为基础模型或用户—券大模型
              ↓
       增量收益/成本预测
              ↓
           补贴 OR
              ↓
       策略价值 surrogate
              ↓
   更新 Adapter，而非整个大模型
```

### 8.2 LLM＋优化层：其他领域的早期尝试

[Decision-informed Neural Networks with Large Language Model Integration for Portfolio Optimization，2025](https://arxiv.org/abs/2502.00828) 将 LLM/注意力表征与投资组合优化层结合，让资产关系和宏观信息的表征接受最终投资决策目标监督。

它说明严格 LLM 表征可以进入 decision-focused 框架，但目前证据来自金融组合优化，不包含 treatment effect、反事实结果和营销预算分配，不能直接作为补贴业务有效性的证据。

### 8.3 GOAL：约束条件化的生成式激励策略

[Generative Optimization for Incentivized Advertising with Global Level Constraints，2026](https://arxiv.org/abs/2608.04421) 将激励分配建模为条件序列生成：

```text
用户历史 + 系统级约束压力
              ↓
层次化因果状态编码器
              ↓
生成激励金额 token
              ↓
SCPO 约束策略优化
```

GOAL 的关键点包括：

- 直接生成连续激励金额，而不是先独立预测每个动作的 uplift；
- 使用用户历史建模延迟反馈与营销疲劳；
- 将 ROI 等全局约束作为条件输入；
- 学习一个能够适应多种约束水平的策略，而不是每个约束重新训练。

它最接近“大模型直接决策”，但属于面向激励的生成式策略，不是使用通用语言知识的 LLM，也仍需要奖励建模和约束校准。

### 8.4 D³-Subsidy：扩散模型生成城市级补贴计划

[D³-Subsidy，2026](https://arxiv.org/abs/2605.20036) 面向网约车司机补贴，使用层次化扩散模型生成未来城市级补贴计划：

```text
固定的历史前缀
      ↓
条件扩散模型生成未来轨迹
      ↓
逆向模块解码成城市级控制信号
      ↓
拉格朗日对偶映射到订单—司机激励
```

其特点是：

- 处理动态供需冲击和序列决策；
- 直接把补贴率上限嵌入执行映射；
- 使用多城市预训练和参数高效微调；
- 避免线上逐订单运行昂贵迭代优化。

它属于扩散式大模型决策，而不是语言模型。其决策粒度是城市级控制，与当前用户级多券 uplift 分配并不相同，但“跨城市预训练＋约束条件化计划生成”值得借鉴。

## 九、传统方法与大模型方法的关系

| 类别 | 预测模块 | 决策模块 | 决策信号能否影响上游 | 是否严格 LLM |
|---|---|---|---:|---:|
| 当前两阶段 | EUEN/EFIN | 分桶＋OR | 否 | 否 |
| DFCL | 因果模型 | OR或surrogate | 是 | 否 |
| Bi-DFCL | 因果模型 | 双层OR目标 | 是 | 否 |
| 直接策略 | MLP/Transformer | 模型直接输出动作 | 是 | 否 |
| 基础模型 DFF | 预训练基础模型 | 优化＋value surrogate | 是 | 不一定 |
| GOAL | 生成式策略模型 | 直接生成激励 | 是 | 否，LLM-like |
| D³-Subsidy | 扩散模型 | 生成计划＋对偶执行 | 是 | 否 |
| LLM＋DFL | LLM语义表征 | 可微优化层 | 是 | 是，但补贴证据不足 |

## 十、当前项目建议采用的研究顺序

### 10.1 第一阶段：复现传统端到端增益

保持现有特征和模型容量，先验证一二阶段对齐是否有价值：

| 实验 | 表征 | 训练目标 | 部署方式 |
|---|---|---|---|
| T0 | 当前 EUEN/EFIN | 当前 loss | 分桶＋OR |
| T1 | 当前 EUEN/EFIN | 决策感知 loss | 分桶＋OR |
| T2 | 小型直接策略网络 | DR 策略价值 | 直接输出动作＋约束校准 |

T1 回答“决策目标对齐是否有效”；T2 回答“是否需要保留原有两阶段链路”。

### 10.2 第二阶段：加入大模型表征

在第一阶段最优框架上分别加入：

| 实验 | 大模型模块 | 目的 |
|---|---|---|
| M1 | 冻结 LLM 用户语义 | 验证用户语义的额外价值 |
| M2 | 冻结 LLM 用户＋券语义 | 验证 treatment 语义与新券迁移 |
| M3 | 行为基础模型＋Adapter | 验证历史预训练与跨期泛化 |

必须保留“相同架构、不使用预训练”和“人工语义特征”对照，避免把模型容量或新增字段收益误认为大模型收益。

### 10.3 第三阶段：探索生成式直接决策

只有当以下条件满足时，再研究 GOAL/D³-Subsidy 类生成模型：

- 存在丰富的重复决策轨迹；
- 动作空间足够大，例如连续金额、组合券或动态券包；
- 能够定义非重叠的长期奖励；
- 历史动作概率或可靠探索数据可恢复；
- 有独立的约束校准和策略评估数据。

对于当前三至四种固定券，生成式模型可能只是用更复杂的方式近似一个小型分类策略，需要先证明其必要性。

## 十一、建议精读顺序

1. **Smart Predict, then Optimize**：理解预测误差与决策 regret 的区别；
2. **DFCL**：理解反事实营销中如何构造决策损失；
3. **Bi-DFCL**：理解观察数据和 RCT 如何通过双层目标结合；
4. **Decision-Focused Fine-Tuning of Time Series Foundation Models**：理解大模型如何接受决策目标的参数高效微调；
5. **GOAL**：理解约束条件化的生成式激励策略；
6. **D³-Subsidy**：理解预训练扩散模型如何产生动态补贴计划。

## 十二、当前最值得验证的研究命题

最适合本项目的近期问题是：

> 在现有 RCT、多券和增量 CAC 约束下，使用最终 OR 策略价值训练 uplift 模型，能否稳定超过当前“预测 loss＋分桶＋OR”；在此基础上，引入用户—券大模型表征是否还能带来独立增益？

对应最重要的四组实验为：

```text
E0：普通表征 + 普通 uplift loss
E1：普通表征 + decision-focused loss
E2：大模型表征 + 普通 uplift loss
E3：大模型表征 + decision-focused loss
```

该设计可以把“两阶段对齐收益”和“大模型表征收益”分开识别，避免一次同时更换表征、训练目标和部署链路后无法解释结果来源。
